# Scraping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Livrer un projet de scraping gratuit et utilisable, versionné sur GitHub.

**Architecture:** Un spider Scrapy utilise HTTP ou Chromium selon un argument.
Les réglages communs limitent le trafic ; un middleware arrête le crawl sur
blocage. Docker Compose et Make exposent les commandes courantes.

**Tech Stack:** Python 3.13, Scrapy 2.20.0, scrapy-playwright 0.0.48, Playwright 1.65.2, pytest, Ruff.

**Spec:** `docs/superpowers/specs/2026-11-18-scraping-design.md`

## Global Constraints

- Aucun service payant ; CI uniquement sur runner standard et dépôt public,
  avec job désactivé si le dépôt devient privé.
- Données, secrets, environnements et outils locaux exclus de Git.
- Dépôt neuf dans le dossier courant ; pas de worktree supplémentaire.
- Tests réseau sur localhost, aucune dépendance à un marchand externe.

## Review Focus

- JavaScript : les citations doivent être extraites après leur apparition.
- robots.txt : une page interdite ne doit pas être demandée.
- 403/429 : aucune nouvelle tentative, aucune page suivante.
- Pagination : max_pages=1 interdit toute deuxième page.
- Windows : commandes sans Make et chemins avec espaces.
